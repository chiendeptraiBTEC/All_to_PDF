# Documentation index

Tài liệu là nguồn sự thật của dự án. Không dùng nội dung hội thoại làm nơi duy nhất lưu quyết định,
tiến độ hay ngữ cảnh.

## Đọc trước khi làm việc

1. [`memory/CONTEXT.md`](memory/CONTEXT.md) — tóm tắt ngữ cảnh hiện tại.
2. [`memory/PROGRESS.md`](memory/PROGRESS.md) — những gì đã hoàn thành và bằng chứng.
3. [`memory/NEXT.md`](memory/NEXT.md) — công việc tiếp theo theo thứ tự.
4. [`memory/FILE_MAP.md`](memory/FILE_MAP.md) — tên file và tác dụng.
5. [`engineering/WORKFLOW.md`](engineering/WORKFLOW.md) — quy trình thay đổi.
6. [`engineering/QUALITY_GATES.md`](engineering/QUALITY_GATES.md) — cổng kiểm định.

## Nhóm tài liệu

- `memory/`: bộ nhớ vận hành, context, tiến độ, rủi ro và bàn giao.
- `architecture/`: cấu trúc hệ thống và ranh giới module.
- `engineering/`: workflow, Definition of Done và tiêu chuẩn code.
- `product/`: chiến lược UX, luồng người dùng và nguyên tắc giao diện.
- `testing/`: chiến lược test và corpus PDF.
- `security/`: baseline bảo mật.
- `ADR-*`: quyết định kiến trúc đã được chấp nhận.
